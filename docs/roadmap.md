# AI万链产品路线

AI万链围绕居家伙伴的连续体验发展：一个中枢维护身份、记忆、对话与受托事项，多类设备把交流和帮助带到用户身边。

[返回项目首页](../README.md)

## 当前基础

已建立手机与音箱交流、记忆保存与检索、叫名唤醒和连续接话、按需视觉问答、实体闹钟执行，以及单机本地部署流程。

## 近期 让日常交流更顺畅

- 降低说完到开口的等待，保持自然音色与完整回答。
- 提升不同表达、环境噪声和话轮衔接下的稳定性。
- 完善记忆的保存、更正与使用体验。
- 整理真实演示与产品案例，开展小规模家庭体验。

## 下一阶段 主动陪伴与居家助理

- 用户可设置的主动问候、关心频率与睡前提醒。
- 与灯光、窗帘和电视等设备协作，营造休息与观影环境。
- 接受会议材料整理委托，在次日合适时间提醒查看与准备。
- 在做饭等日常活动中提供步骤建议，结合授权的视觉输入协助判断。
- 支持外出时通过手机联系中枢、查看和安排受托事项。

## 长期 扩展现实执行能力

通过兼容设备和机器人扩展行动能力，让用户继续与同一份角色和记忆交流。具体接入随设备能力、可靠性和家庭使用反馈推进。

每一阶段都围绕用户是否更轻松、任务是否真正完成，以及日常维护是否方便来判断价值。
